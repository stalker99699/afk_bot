# AFK_Bot+

> 🤖 *Этот проект на 100% сгенерирован с помощью ИИ. Простите меня.*

Самый базовый AFK-бот для Minecraft на Node.js с автоматическим переподключением, отправкой команд при входе и полным перезапуском процесса при критических ошибках.

## Возможности
- 🔄 Автоматическое переподключение при кике или разрыве связи
- 💬 Отправка команд/сообщений при входе (например, `/register`)
- ⏳ Случайные задержки между попытками переподключения
- 🛡️ Защита от бесконечных циклов: при превышении лимита попыток бот полностью перезапускает сам себя (спавнит новый процесс)
- ⚙️ Простая конфигурация прямо в `afk_bot.js`

## Установка
```bash
npm install mineflayer
```

## Настройка
Откройте `afk_bot.js` и измените блок `config` под себя:

```javascript
const config = {
  host: 'localhost',       // Адрес сервера
  port: 25565,             // Порт сервера
  username: 'AFK_Bot',     // Ник бота
  version: '1.20.1',       // Версия Minecraft
  auth: 'offline',         // Тип авторизации (offline)

  // Приветственное сообщение (отправляется при входе)
  welcomeMessage: '/register 123 123',
  messageRepeatCount: 2,   // Сколько раз отправить сообщение
  messageInterval: 1000,   // Задержка между отправками (мс)

  // Настройки переподключения
  maxReconnectAttempts: 10,// Лимит попыток до полного перезапуска
  minReconnectDelay: 1000, // Мин. задержка перед переподключением (мс)
  maxReconnectDelay: 10000 // Макс. задержка перед переподключением (мс)
};
```

## Запуск
```bash
node afk_bot.js
```
