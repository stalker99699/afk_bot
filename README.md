AFK_Bot

Description: Самый базовый AFK бот для Minecraft на Node.js с автоматическим переподключением и приветственными сообщениями.

Installation: npm install mineflayer

Features:

    Автоматическое переподключение при отключении

    Отправка приветственных сообщений при входе

    Случайные задержки между переподключениями

    Защита от бесконечных попыток переподключения

    Простая конфигурация в коде
