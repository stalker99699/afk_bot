# AFK Bot
🤖 Этот проект на 100% сгенерирован с помощью ИИ. Простите меня. / 🤖 This project is 100% AI-generated. Forgive me.

Простейший AFK-бот для Minecraft на Node.js с использованием библиотеки `mineflayer`.

## Установка
```bash
git clone https://github.com/stalker99699/afk_bot.git
cd afk_bot
npm install mineflayer
```

## Настройка
Откройте `afk_bot.js` и укажите параметры вашего сервера:
```javascript
host: 'localhost',      // IP сервера
port: 25565,            // Порт
username: 'AFK_Bot',    // Ник бота
version: '1.20.1',      // Версия Minecraft
auth: 'offline'         // Только offline-режим (Microsoft не поддерживается)
```

## Запуск
```bash
node afk_bot.js
```
